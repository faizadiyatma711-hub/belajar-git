# Latihan Git & GitHub 🚀

Repositori ini berisi catatan dan hasil latihan saya dalam mempelajari dasar-dasar *Version Control System* menggunakan **Git** dan **GitHub**.

## 🛠️ Proyek / File yang Ada
Di dalam repositori ini, terdapat beberapa file hasil latihan:
- `index.html` : Halaman utama proyek.
- `login.html` : Halaman login yang dibuat pada *branch* terpisah (`halaman_login`) lalu digabungkan (*merge*) ke *branch* utama (`main`).

## 📚 Apa Saja yang Sudah Dipelajari?
Selama latihan di sini, saya telah mempraktikkan beberapa perintah penting Git:
- **Inisialisasi & Riwayat:** `git init`, `git log`, `git diff`
- **Manajemen Branch:** `git branch`, `git checkout` / `git switch`, dan `git merge`
- **Kolaborasi Remote:** Menghubungkan repositori lokal ke GitHub via SSH dan melakukan `git push`
